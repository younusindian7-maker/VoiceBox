# VoiceBox Scripts

## Purpose

This directory contains development, setup, maintenance, testing,
and local processing scripts used by VoiceBox.

## Planned Script Categories

- Development setup
- Environment checks
- Model management
- Media preparation
- Testing
- Maintenance
- Backup and recovery

## Script Principle

Scripts should be:

- Reproducible
- Clearly documented
- Safe to run
- Platform-aware where necessary
- Independent from user data

## Safety Rule

Scripts must not delete, overwrite, or modify user data without an
explicit and documented reason.

## Current Status

No executable project scripts have been implemented yet.
