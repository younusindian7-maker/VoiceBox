# VoiceBox Models

## Purpose

This directory documents and will contain the local AI models used by
VoiceBox.

## Planned Model Categories

- Speech-to-Text
- Speaker Detection / Diarization
- Translation
- Voice Generation
- Optional Audio Processing

## Model Requirements

Each model must be evaluated for:

- License
- Language support
- Local execution
- Hardware requirements
- Memory usage
- Processing speed
- Output quality
- Integration compatibility
- Offline operation

## Model Storage

Large model files should not be committed directly to the Git
repository unless there is a specific reason to do so.

Model download and installation procedures will be documented
separately.

## Selection Rule

No model is considered production-ready until it has been tested
inside the VoiceBox pipeline.

No AI model has been selected or installed yet.
