# VoiceBox Output

## Purpose

This directory is reserved for locally generated VoiceBox output
during development and testing.

## Planned Output

- Processed audio
- Dubbed video
- Preview files
- Temporary render results
- Test exports

## Repository Rule

Generated media files should normally remain outside Git history.

Large video and audio files must not be committed to the repository
unless specifically required.

## Privacy

Generated output may contain user media and should be treated as
private development data.

## Current Status

No generated media has been added yet.
