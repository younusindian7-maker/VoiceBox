# VoiceBox Tests

## Purpose

This directory contains tests and verification resources for VoiceBox.

## Planned Test Areas

- Media input validation
- Audio extraction
- Speech detection
- Speaker detection
- Speech-to-text
- Translation
- Voice generation
- Timing synchronization
- Audio mixing
- Video rendering
- End-to-end dubbing

## Testing Principle

Each major component must be tested before being considered stable.

Tests should use controlled sample media where possible.

## Checkpoint Rule

A feature should not be promoted to `main` until its relevant tests
have passed.

## Current Status

Automated application tests have not been implemented yet.
