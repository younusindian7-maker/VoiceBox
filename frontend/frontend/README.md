# VoiceBox Frontend

## Purpose

The VoiceBox frontend will provide the user interface for managing
video dubbing projects.

## Planned Responsibilities

- Select or upload video
- Create and manage projects
- Select source and target languages
- Display processing progress
- Show transcription and translation segments
- Configure voice and audio options
- Preview original and dubbed results
- Export the final video
- Display project history and status

## Design Principle

The frontend should communicate with the backend through clearly
defined interfaces.

UI logic should remain separate from AI models and media-processing
implementation.

## Offline-First Principle

The interface should support the local/self-hosted workflow and
should not require a paid cloud service for the core application.

## Current Status

Frontend implementation has not started.

This document defines the frontend foundation before UI implementation.
