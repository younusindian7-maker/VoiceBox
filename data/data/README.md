# VoiceBox Data

## Purpose

This directory is reserved for local development data used during
VoiceBox testing and processing.

## Planned Data

- Temporary media metadata
- Test input references
- Intermediate processing data
- Development-only datasets

## Privacy

User media should remain under user control.

Personal videos, audio recordings, voice references, and other private
media should not be committed to the Git repository.

## Repository Rule

Large media files and generated outputs should not be committed to
Git unless specifically required.

## Current Status

No user media or development dataset has been added yet.
